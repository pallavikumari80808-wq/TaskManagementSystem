# Task Management System

## Project Overview
Task Management System is a beginner-friendly command-line application developed using C++. It helps users organize and manage their daily tasks through a simple menu-driven interface.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Input validation
- Menu-driven navigation

## Technologies Used
- C++
- Standard Template Library (STL)
- Visual Studio Code
- MinGW G++ Compiler

## Setup Instructions

**Step 1:** Clone the repository.

```bash
git clone https://github.com/pallavikumari80808-wq/TaskManagementSystem.git
```

**Step 2:** Open the project folder in VS Code.

**Step 3:** Compile the program.

```bash
g++ main.cpp -o TaskManager.exe
```

**Step 4:** Run the application.

```bash
.\TaskManager.exe
```
